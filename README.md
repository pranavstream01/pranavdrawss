# Pranav Karde Portfolio

Static portfolio website. The entry point is `index.html`.

## Publish with GitHub Pages

1. Open repository Settings → Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Select `main` and `/ (root)`, then Save.
4. Wait for the Pages deployment to complete.

All media and project assets are kept under `assets/` and must remain at their relative paths.
